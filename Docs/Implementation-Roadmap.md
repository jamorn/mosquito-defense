## 📱 ก้อน 0 — Mobile-First Foundations (สำคัญที่สุด)

**เป้าหมาย**: ทำให้เกมเล่นได้อย่างสบายบนโทรศัพท์/แท็บเล็ต ก่อนทำระบบอื่นต่อ

**ว่าทำไมต้องมาก่อน**: วิสัยทัศน์ "Global Edition" คือเด็กทั่วโลก (หลายคนเล่นมือถือราคาประหยัด ไม่ใช่ PC) ถ้าทำ Pause/Planning/Health ก่อนแล้วมือถือใช้ไม่ได้ จะต้องกลับมาแก้ใหม่

### 0.1 Pointer Events (mouse + touch รองรับหมด)
- ปัจจุบัน: `onClick` อย่างเดียว → ต้องรองรับ `pointerdown/move/up` / `touch`
- แทนที่ event เดิมให้เป็น **PointerEvent** (รองรับ mouse, touch, stylus เดียวกัน)
- ป้องกันแยกของ "scroll/pan" กับ "tap" (มือถือ)

### 0.2 Ghost Preview (วางป้อม ที่เห็นก่อนลง)
- ป้อมโปร่งแสง (ghost) ติดตามนิ้ว/เมาส์
- **สีเขียว/ขาว** = วางได้ , **สีแดง** = วางไม่ได้ (on path / ซ้อนป้อม / นอกขอบ)
- **โชว์วงกลมรัศมียิง (range)** ตอน preview → เห็นว่าครอบทางเดินแค่ไหน
- สำคัญมากสำหรับเด็กบนมือถือ: "เห็นก่อนแตะ กันแตะพลาด วางผิดที่แล้วแก้ยาก"

### 0.3 Touch Target ≥ 44px
- ปุ่มสำคัญ (วาง/อัป/ขาย/ไอเทม) ให้ขนาดใหญ่พอสำหรับนิ้วเด็ก (~44–48px)
- UI ที่ตอนนี้เล็กไปต้อง enlarge

### 0.4 ซูม + เลื่อน (Pan & Zoom) — กันจอเล็ก
- ตัวเลือก: (a) เต็มขั้น pinch + pan, (b) ปุ่ม +/- ซูม + ลากเลื่อน
- ต้องการ: เห็นป้อม/ทางเดินชัด บนจอเล็ก

### 0.5 ร้านค้า / Icon UI ตัวใหญ่ (สำหรับเด็ก)
**ไอเดียเสริม**: icon ร้านค้า (ป้อม, ไอเทม) ต้องทำตัวใหญ่ๆ ให้เด็กมองเห็นชัด
- icon ป้อม/ไอเทมใน `TowerShop` + `ItemBar` แสดงใหญ่ชัด (ไม่ใช่ไอคอนเล็กๆ)
- ติดป้าย/ตัวเลขสำคัญ (ราคา 🪙, ระดับ ⭐) ให้อ่านง่าย
- สีสด/มีกรอบ/มีพื้นหลัง เพื่อเด่นจากพื้นหลัง
- วิธีนี้ช่วยทั้ง "มองเห็นชัด" + "แตะง่าย" (สอดคล้องกับ 0.3)

**🎨 รอตัดสินใจ**:
- [ ] 0.4 เอาแบบ (a) pinch หรือ (b) ปุ่มซูมก่อน? (มือถือถูกบางรุ่น pinch ไม่เนียน)
- [ ] 0.5 icon ร้านค้า: ต้องการให้แสดง "เงินที่ต้องมี / ราคา" ใหญ่ๆ ด้วยไหม? (ช่วยเด็กคำนวณ)

## 🏰 ก้อน 1 — Tower Placement UX (วางป้อมอย่างฉลาด)

**เป้าหมาย**: ให้วางป้อมง่าย แม่น เห็นผลชัด (ทั้ง PC + มือถือ)

### 1.1 กลไกการวาง
- จากเดิม "คลิกวาง" → ใช้ **Ghost ติดตาม cursor/นิ้ว** แล้ว **ชี้+คลิก/แตะ** = วาง
- (หมายเหตุ: ที่คุยกันสรุปว่า **ไม่ต้อง "กด-ลาก-ปล่อย"** ใช้ "ชี้+แตะ" ง่ายกว่าสำหรับเด็ก)

### 1.2 Visual Feedback
- Ghost สีเขียว/แดง = ลงได้/ไม่ได้ (มีรัศมี range)
- เมื่อวางไม่ได้ → ให้ hint สั้นๆ ว่าทำไม (เช่น "ซ้อนป้อม", "บนเส้นทาง")
- เมื่อวางได้ → effect sparkles + เสียง (มีอยู่แล้ว)

### 1.3 Snap / Helper (เสริม)
- เลือกได้ว่าจะให้ "snap กับกริด" หรือ "วางอิสระ"
- (แนะนำ snap เวอร์ชันมือถือ ช่วยให้แม่นกว่า)

**🎨 รอตัดสินใจ**:
- [ ] ต้องการ "snap to grid" ไหม หรือวางอิสระ?
- [ ] hover info (ข้อมูลยุง) วางไว้ตรงไหน? (มือถือไม่มี hover → เปลี่ยนเป็น "tap ค้าง")

## ⏸️ ก้อน 2 — Pause / Resume

**เป้าหมาย**: หยุดเกมได้ทุกเมื่อ (พื้นฐานของทุกเกม + เป็นฐานของ Planning Mode)

### 2.1 กลไก
- State `paused: boolean` + ปุ่ม ⏸/▶ ใน TopBar
- Pause = **ยุงหยุด, ป้อมหยุดยิง, spawn หยุด, timer หยุด**
- **ยังวาง/อัป/ขายป้อมได้ตอน pause** (เตรียมกลยุทธ์)
- ห้ามกด pause ตอน `gameOver || gameWon`

### 2.2 Cooldown เมื่อ pause
- Item cooldown **ไม่นับต่อ** ตอน pause (= "เวลาหยุด" ตามความรู้สึก)

### 2.3 Render / เสียง ตอน pause
- ยุง/ป้อม/animation ของเกมหยุด แต่ **UI ยังทำงาน** (คลิกเมนูปกติ)
- เสียงเกมควรหยุด? (รอตัดสินใจ — แนะนำให้ปิด effect ตอน pause)

**🎨 รอตัดสินใจ**:
- [ ] เปิดวางป้อมตอน pause ใช่ไหม (ผมแนะนำใช่)
- [ ] เสียงตอน pause: ปิด effect ทั้งหมด หรือ เปิดนิ่งไว้?

## 🗺️ ก้อน 3 — Planning Mode (โหมดวางแผน)

**เป้าหมาย** (ไอเดียของคุณ): ให้เด็กรู้จัก "คิดก่อนลงมือ" — แพ้ก็ได้แผนใหม่ก่อนเริ่ม

### 3.1 "Pre-Wave Planning" ก่อนเริ่มคลื่นใหม่ทุก wave
- เข้า "โหมดวางแผน" อัตโนมัติก่อนคลื่นเริ่ม + WaveIndicator โชว์ข้อมูลคลื่น
  (Note02: ยุงอะไรบุก + แพ้ทางด้วยอะไร)
- กด "เริ่ม" เมื่อพร้อมเท่านั้น ทำได้สั้นๆ

### 3.2 "Retry Planning" หลังแพ้ (ไอเดียเด่น)
```
💀 แพ้ Wave 7 → กด Retry
   ↓
⏸ "โหมดวางแผน" อัตโนมัติ (หลังแพ้+ก่อนเริ่ม)
   ↓
🤔 รู้ว่าคลื่นนี้คืออะไร (จากบทเรียน/Death Report)
   ↓
🏰 วาง/อัป/ขายป้อมล่วงหน้าได้ (โดยไม่เร่งรีบ) + เห็น preview
   ↓
▶️ กด Resume → เริ่มเล่นจริง วางต่อได้เลย
   ↓
😌 เล่นอย่างมั่นใจ ฝึกวางแผน
```

### 3.3 เทรนนิ่งโหมด (optional)
- ปุ่มตัวเลือก "โหมดฝึก" = unlimited เวลาวางแผน vs จำกัดเวลา
- ให้คุณพ่อ/ครูเลือกได้

**🎨 รอตัดสินใจ**:
- [ ] Q1 ตอนก่อน "wave แรกสุด" ก็เข้าอยู่โหมดวางแผนเลยไหม? หรือเริ่มเลย (ยังไม่มี clue)
- [ ] โหมดวางแผนใช้เงินจิง (ต้องมีเงินพอ) ปกติไหม? (แนะนำว่า ใช่)

## 🏥 ก้อน 4 — Health System + Death Report + Defeat Message (หัวใจเกมเพื่อการศึกษา)

**เป้าหมาย**: จาก "แพ้ทื่อๆ" → "บทเรียนที่จดจำ" ตาม Note03/Note04

### 4.1 Health System (Note04)
- แทนที่ `lives:20` → `HealthSystem` (HP 100%)
- แต่ละยุงมี BITE_DAMAGE (ตามชนิด) + INFECTION_CHANCE
- 5 สถานะ: HEALTHY → MILD → SICK → CRITICAL → DEAD
- ระบบติดเชื้อ (Infections) ตาม disease.config
- UI `HealthBar` (เขียนไว้แล้ว) + แสดงอาการ/โรคที่ติด

### 4.2 Death Report (Note03)
- GameOver → `DeathReportOverlay` (เขียนไว้แล้ว)
- โชว์: "ถูกยุงอะไรกัด" + โรค + ทำไมถึงตาย + วิธีป้องกัน + สถิติ

### 4.3 Defeat Message (Defeat Message System)
- ข้อความให้กำลังใจสุ่ม + เคล็ดลับป้องกัน (7 ภาษา, เขียนไว้แล้ว)
- ตอนแพ้ → แสดง message ให้กำลังใจ + บทเรียน

**หมายเหตุ**: เขียน code ไว้เกือบครบแล้ว เหลือ **เชื่อมกับ App.tsx** + จัดการกับ save/load (ตอนนี้เก็บ `lives` ต้องเปลี่ยนเป็น hp)
- [ ] วิธีจัดการ save/load: เก็บ HP ไว้ด้วยไหม? หรือเริ่มใหม่ทุก load?
