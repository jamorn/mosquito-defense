แบบที่ 1: "Free to Play, Pay what you want" (แนะนำที่สุด!)
┌─────────────────────────────────────────────────────────┐
│ │
│ 🎮 เกม: แจกฟรี 100% │
│ → ทุกคนเข้าถึงได้ │
│ → โรงเรียนใช้ได้ │
│ → ครอบครัวรายได้น้อยได้เล่น │
│ │
│ 💝 Donation: ตามศรัทธา │
│ → $0 ก็ได้ (เล่นฟรี) │
│ → $1 ก็ได้ (สนับสนุน) │
│ → $5, $10, $50 ก็ได้ (ขอบคุณ) │
│ │
│ ผลลัพธ์: │
│ - คนเล่นเยอะ (หลักหมื่น-แสน) │
│ - บางคนบริจาค $5, $10 │
│ - รายได้รวม > ราคา $1 แน่นอน │
│ - ได้ชื่อเสียง + Impact │
│ │
└─────────────────────────────────────────────────────────┘
